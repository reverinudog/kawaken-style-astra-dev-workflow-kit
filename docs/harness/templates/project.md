# 導入先の設定テンプレート

導入先のPROJECT.mdへ記入するための骨格。空欄を推測で実行許可にしない。
未確定の値はそれに依存する操作の前に確認し、独立した調査は進める。

| 項目 | 記入する内容 |
| --- | --- |
| 製品・利用者 | 何を誰のために作るか |
| 種別・対象端末 | ゲーム / アプリ / Webサービス、OSとviewport |
| 技術構成 | 言語、既存依存、起動方法 |
| データ | 正本、保存形式、隔離した検証領域と切替方法 |
| 保護契約 | 維持する動作、互換性、文言、権限 |
| 設計資料 | 製品側の正本へのリンク |
| 基点・保護branch | 正確なbranch名 |
| Git完了の意味 | 「ハンドオーバー」で行うcommit / push / PR / merge / cleanupの終点。既存承認から決め、不明な外部操作を許可済みにしない |
| 検証 | 対象case/fileの実行方法、文書チェック |
| 外部連携 | Geminiのモデル・費用・送信範囲、GPT-6 Proのブラウザ利用可否、制作ツール。秘密値は書かない |
| 配布 | channel、公開範囲、本番変更の承認方法 |
| 説明と回答 | HTML表示、回答受付の有無、未接続時の方法 |
| 新しい依存 | 追加の条件 |
| 証跡 | 画像はscreenshots/、ログや回答の保存・配布範囲 |

既存設定から読み取れる値は親が記入する。未確定事項はそれが必要な工程だけの判断点にする。
導入結果と実接続確認は.local/setup-result.mdに置き、「準備済み」と「実接続済み」を区別する。
