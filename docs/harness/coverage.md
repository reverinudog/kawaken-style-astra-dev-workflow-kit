# 収録した運用の対応表

元環境の運用を、作品の内容・実データ・個人設定を移さずに再構成した。
単に名前を置換せず、導入先のゲーム・アプリ・Webサービスで使える契約へ分けた。

| 運用 | 収録先・実行できること |
| --- | --- |
| 一文字からの開始 | start、astra-session-start。ぬ、あ等からHTML一覧。空一覧・候補・回答・再開 |
| 小タスク登録と大きな仕様相談 | task-planning、templates/task。既存調査、重複、正例/負例、判断、仕様、登録検査 |
| 親による調査・実装 | task-start、ownership。保護契約、必要な構造変更、周辺回帰、行き詰まりの切替 |
| 自己レビューと独立レビュー | review、ownership。担当分離、指摘修正、必要な再検証 |
| UIの設計と実画面確認 | ui。情報階層、全画面の重複、長文・失敗・操作、主観品質の確認 |
| AI応答・保存・認証 | ai-contract、data、security。入出力、互換性、中断、権限、実データ隔離 |
| テストの選択 | verification、release-qa、verification-handoff。費用対効果、成功の再利用、未確認の明示 |
| 分かりやすい説明と回答 | communication、html-feedback。短い図解、比較、途中保存、一覧提出、同じタスクの再開 |
| 作業の継続と離席 | queue。依存順、承認済み終点、失敗した前提、再開点 |
| Git完了と作業場所 | handover、worktrees。commit、PR、merge、所有範囲の後片付け、identityの確認 |
| 教訓の蓄積と再利用 | lessons、LESSONS。索引検索、条件・原因・予防策、更新・廃止 |
| Geminiの視覚・創作相談 | gemini-rescue、advice/gemini.py。実画像、限定文脈、dry-run、一度の送信、親の再確認 |
| GPT-6 Proへの相談 | consult-pro、advice/bundle.py。限定Git資料、指定モデルの確認、添付・送信・回収 |
| 画像・音・動画の制作 | media。ツール接続、採用部分の保持、素材の権利、編集データ、実再生、全件納品 |
| 配布と更新情報 | release、release-qa、release-notes。実成果物、版・基点、更新経路、利用者向け文案 |
| 導入と更新 | SETUP、setup.py。環境点検、許可一覧から配置、競合保持、親による統合、機能別接続結果 |

## 移植時に固定しないもの

- 特定製品の遊び方、物語、人物、素材、バランス、画面名、販売文言、実際のタスク・教訓原文。
- 特定のbranch、端末解像度、技術構成、保存変数、配布ストア、画像・音声provider。
- 元環境専用の外部実装者・メッセージDB・ユーザースコープhook。親Astraと必要な独立レビューへ統一。
- 個人の生成済み素材庫、フォント、音源、APIキー、端末パス、モデル契約。

画像・音声・動画のエンジン、ブラウザ操作、配布先CLIは導入先で利用可能なものを接続する。
運用手順とセットアップの責任は収録するが、外部製品そのものや利用権をこのrepoが再配布するものではない。
