開発手順と補助ツール

CodexのAstraで調査・設計・実装・レビュー・検証を進めるためのルール、スキル、テンプレート、補助ツールを収録しています。

04 / 導入する

導入先の設定と既存ルールの統合

既存のルールや実装を保持し、必要な部分を統合します。

1. 導入新規プロジェクトへ配置。既存の場合は差分を見て統合。
2. 設定PROJECT.mdへ対象製品と実行・検証方法を記入。
3. 依頼「この不具合を直して」「まず仕様を相談したい」と目的を伝える。

SETUP.mdを指定してセットアップを依頼すると、Codexが環境確認・配置・統合・検証を行います。ログイン・APIキー発行・契約の選択は利用者が行います。

MITライセンス / OpenAI公式製品ではありません。
05 / 依頼例

依頼に対応する機能

ぬタスク一覧HTML。選択・自由記入・途中保存・一括提出。
ハンドオーバー記録、教訓、確認、承認されたGit統合と後片付け。
LESSONに残して条件と予防策を記録し、次の関連作業で読む。
Geminiレスキュー実画面の見た目・デザイン、創作を相談。APIキーが必要。
GPT-6 Proに相談限定した資料でブラウザ相談。本人のログインとモデル利用権が必要。

自動再開は導入先のCodexデスクトップで実接続を確認。外部相談の準備済みと実送信済みは区別します。
