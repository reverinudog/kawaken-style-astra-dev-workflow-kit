# 運用の全体点検と導入の簡略化

## 目的

ゲーム・アプリ・Webサービスで使えるAstra運用一式として、開始から相談・実装・教訓・引き継ぎまでをつなぐ。
作品の内容・個人情報を含めず、導入先へ読み込ませ「セットアップ」で必要な準備を親が進める。

## 完了条件

- 一文字開始、HTML選択と空一覧、handover、LESSON検索・記録が入口から見つかる。
- Gemini画像/創作相談とGPT-6 Proの限定資料・ブラウザ相談、秘密入力を同梱する。
- 新規・既存導入でファイルを選んで配置し、ユーザー変更・秘密・既存設定を保持する。
- 元の運用との対応表、本人の操作が必要な条件、未検証の接続を明記する。
- 自己レビュー、独立レビュー、指摘修正、対象テスト、混入監査を完了する。
- READMEを実装済みの機能・依頼例・導入手順・制約に合わせて更新する。

## 検証

文書参照とskill書式、導入の冪等性と競合保持、資格情報、外部送信の境界、Git限定資料、タスク一覧、既存HTML受付を対象にする。
APIの有料送信とProへの実資料送信はこの追加作業で行わない。

## 結果

23workflow・19skillへ拡張し、対応表、導入ツール、限定相談ツール、LESSONS索引、一文字入口、空一覧を追加。
READMEを依頼例、セットアップ、機能、認証条件、確認済み範囲が分かる内容へ更新した。
文書検査・skill検証・Node10件・Python24件が成功。実ブラウザで一覧の入力と再読込、
同じURLの空一覧への切替、旧版入力保持を確認した。前工程の自動再開・受領の実接続結果も再利用した。
独立レビューの未追跡本文混入とCommonJS導入の2件を修正し、回帰検証と読み取り再レビューで解消を確認。
有料外部通信、macOS/Linux実機、導入先ごとの実接続は未確認として明記した。
