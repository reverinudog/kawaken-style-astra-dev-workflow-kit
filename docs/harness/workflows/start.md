# 次の作業を選ぶ

「次なに」「始めよう」と、意味のない一文字（例：「ぬ」「あ」「x」）をタスク一覧のショートカットとして扱う。
質問への一文字の回答、記号やデータとして意味のある入力は対象外。進行中の依頼を勝手に取り消さない。
明示的に一覧を求められた場合は進捗を保持して表示し、次の選択を待つ。

1. branch、status、worktreeとPROJECT.mdを確認する。読み取りだけでbranchを切り替えない。
2. [タスク一覧](../NEXT_TASKS.md)を読み、候補と判断待ちを短く示す。
3. ユーザーが選んだ作業だけ仕様を読み、[作業開始](task-start.md)へ進む。
4. 一覧が空でも「未完了の登録タスクはありません」とHTMLで表示する。架空タスクを作らない。

通常は[HTML回答](html-feedback.md)のタスク選択で、候補・選択・自由記入・提出を用意する。
利用者が見るだけを求めた時と空一覧は説明専用表示にし、回答受付や通知接続を要求しない。
