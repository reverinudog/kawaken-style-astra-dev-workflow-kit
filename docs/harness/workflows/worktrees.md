# 作業場所を分離する

現在のcheckoutで安全に作業できるならそこを使う。
別作業が利用中、所有範囲が衝突、明示的な隔離指定がある場合にworktreeを使う。

作成前にbranch、status、worktree一覧、PROJECT.mdの基点を確認する。
作成直後にHEADと期待したrefを照合する。元checkoutを編集しない。
所有者、作業branch、パス、変更範囲を記録する。

dirty、locked、利用中、未統合のworktreeを移動・削除しない。
他者の変更をstash、reset、強制checkoutして場所を空けない。

後片付けは統合済みでclean、他作業が利用しておらず、成果が保存済みと確認してから通常のGit手順で行う。
対象パスが意図した場所に収まることを確かめ、未確認ディレクトリを再帰削除しない。
保持プロセスがある時は所有者を確認し、無関係なアプリやサーバーを止めない。

統合先checkoutがdirtyならfetchとremoteの確認までとし、ローカル未同期を報告する。
