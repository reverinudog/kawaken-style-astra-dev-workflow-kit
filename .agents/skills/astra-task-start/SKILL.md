# astra-task-start

[共通入口](../../../AGENTS.md)と[導入先設定](../../../PROJECT.md)を確認し、
[task-startの手順](../../../docs/harness/workflows/task-start.md)に従う。
手順本文はworkflowを正本とし、今回の依頼・承認範囲・完了済みの証拠を引き継ぐ。
利用できない外部ツールや個人スキルを仮定しない。
